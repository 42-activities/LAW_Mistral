# P6 LLM — implementation notes

**Spec:** §5. The LLM is language in / language out only; the deterministic engine stays the
source of truth.

- `app/modules/llm/provider.py` — `LlmProvider` protocol; `MistralProvider` (stdlib HTTPS,
  temperature 0, JSON mode for parsing). Configured by `APP_MISTRAL_API_KEY` /
  `APP_MISTRAL_MODEL` (default `mistral-large-latest`); no key → no provider.
- **Job 2, summaries** (`summary.py`, prompt `summary-v1`): top-3 complete ScoreCards as JSON →
  prose with `[n]` citation tags. **Grounding validator** (`grounding.py`): every number must
  match an input value (format tolerance), every citation must be an input citation, every
  percentage sentence must carry a citation, every jurisdiction and list mentioned must be in the
  input, no dates outside the input. One repair attempt quoting the errors; then the
  deterministic template. No provider → template.
- **Job 1, NL questions** (`ask.py`, prompt `nl-parse-v1`, `POST /v1/ask`): question → JSON
  `QueryIntent` validated against known jurisdictions/categories → `WithholdingEngine` → answer
  rendered by a fixed template (no model-written figures at all). No provider → 503.
- **Audit:** `workflow.llm_interaction` (migration 0016) — one row per model call with attempt,
  output, grounding status/errors, citations, latency and token counts. `cost` stays NULL: no
  price list is configured and prices are never estimated.
- **Deploy:** repository secret `MISTRAL_API_KEY` is written to the server `.env` line of the
  same name on every deploy; compose passes it to the API.
- **Web:** results page shows the summary labelled "AI-generated narration of the figures
  below" (or "Summary … fixed template, no AI"); new `/ask` page.
